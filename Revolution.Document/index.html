1第一次用：从这里开始

这三个模块是"完全没接触过框架也能照着做完"的手把手文档，也是最常用的三件事：打日志、写计时、每帧回调。

📝日志系统小白向

分级输出（Debug 正式包编译期删除）、模块标签静音、刷屏抑制、环形缓冲看现场、异步落盘。

使用说明

⏱计时器系统小白向

一行创建（到点 / 每间隔 / 下一帧 / 服务器时刻）、四时间域、句柄代际失效、作用域一行全停。

使用说明

🧵公共 Mono 模块小白向

让纯 C# 类也能每帧跑（Update / LateUpdate / FixedUpdate）与协程宿主；去重、上限、异常隔离。

使用说明
推荐阅读顺序：日志 → 计时器 → 公共 Mono → 资源加载 → UI → 动作序列。 前三篇决定你"怎么观察、怎么排时序"，后面三篇是业务天天要用的三件套。

2业务四件套：资源 · UI · 动作 · 场景

日常开发用得最多的四个模块。它们的《架构解析》里都带了完整数据流与失败处理说明。

📦资源加载系统

编辑器直读 + AB 两条后端、引用计数、自动卸载、失败原因可查；含 RevAB 打包工具的分包 / 依赖 / 体积 / 漏标 / 快照。

使用说明 架构解析 .md

🎨UI 系统

🎬动作序列

链式 DSL 表达"播放 → 等待 → 并行 → 嵌套"，构建与播放分离，取消也有收尾契约。

使用说明 架构解析 .md

使用说明

🎮状态机

📣事件系统

强类型事件 + 订阅句柄（取消订阅不用记委托）；派发期间增删订阅的安全语义写在文档里。

使用说明 架构解析 .md

🗺场景系统小白向

一行切场景（await 或挂事件）、进度永远 0~1（不卡 90%）、加载界面最短展示时长、切前按约定清理（默认清对象池）。

使用说明架构解析

＋扩展包：按需安装

不属于框架本体，单独一个包：导入即有、不导入零影响 —— 框架侧只多了两个默认为 null 的钩子，业务加载代码不用改。

🔄资源热更新（RevHotUpdate）

清单驱动版本比对与差量下载（只下变化过的包）、断点续传、多源降级、尺寸 + SHA-256 校验、版本目录原子切换与回滚；Android 首包落地、小游戏走版本化 URL + 引擎缓存。

⚡ 想先跑起来看：示例 Assets/Revolution.Demo/RevHotUpdate.Demo/（一键装配本地 CDN + 起本地假 CDN + 面板三步，不需要真云账号）。

🛠 配套发布工具：主推 Revolution.Could（腾讯云 COS 热更发布 WPF 可视化工具，源码在仓库根 Revolution.Could/：选产物 → 校验 SHA-256 → 按安全顺序上传）；另有 UploadToCos / UploadToOss 命令行脚本给 CI 用。三者都内置"内容先传、清单最后传"纪律。

使用说明 架构解析 技术方案 .md
