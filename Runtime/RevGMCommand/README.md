# GM 指令框架（RevGMCommand）—— 3 分钟上手

> **一句话**：一行代码注册一条 GM 指令，编辑器面板里边打边联想、回车执行，结果与耗时直接回显。
> 运行时 12 个 `.cs`（11 个纯 C#、不引用 UnityEngine；`Support\RevGMUnityHooks.cs` 是唯一的 Unity 钩子），编辑器侧 2 个 `.cs`（EditorWindow，**不占用运行时、不进包体**）。

## 一、一行注册

```csharp
public static class MyGameCommands
{
    [RevGMEntry("战斗 / 经济 相关")]                 // 只在"想在编辑期看到命令清单"时才需要
    public static void Register()
    {
        // 一行一条 —— 名字里的 / 会自动长成分组树
        RevGM.Register("经济/加金币", "给当前玩家加金币", args => AddGold(args.Int(0, 1000)),
                       RevGMArg.Int("数量", 1000));

        RevGM.Register("战斗/清空全场敌人", "把所有敌人血量清零", args => ClearEnemy(),
                       RevGMFlags.HighRisk);          // 高危：面板执行前二次确认
    }
}
```

面板：菜单 **Revolution.Tools/GM 指令面板**（`Ctrl+Shift+G`）。代码里也能直接执行：`RevGM.Execute("经济/加金币 500")`。

## 二、面板怎么用（4 步）

| 步骤 | 操作 |
|---|---|
| ① 找命令 | 搜索框里边打边看联想：**前缀 / 连续子串 / 字符级缩写**都能命中，命中字高亮 |
| ② 选/补全 | `↑` `↓` 选联想项，`Tab` 用它补全（自动补一个空格，接着打参数） |
| ③ 执行 | `Enter` 执行；`Ctrl+Enter` 跳过高危确认；`Esc` 清空。结果、成功失败、耗时显示在下方 |
| ④ 看详情 | 左侧分组树点一条 → 右侧显示说明与参数（枚举候选值点一下就填进输入框）；双击 = 填入 |

**编辑模式 vs Play 模式**：编辑模式只查看与联想（命令清单来自 `[RevGMEntry]` 入口的快照）；**Play 模式下读的是运行期真实注册表，可真执行**（被测环境就是游戏本身）。

## 三、目录（只有前两个是你必须看的）

| 文件 | 行数级别 | 说明 |
|---|---|---|
| `Facade\RevGM.cs` ★ | 入口 | 一行注册（6 个重载）/ `Execute` / `Suggest` / `Clear` / `Enabled` |
| `Core\RevGMArgs.cs` ★ | ~200 行 | 取参数：`Int` / `Float` / `Bool` / `Str` / `Enum`（都带默认值，解析失败给人话） |
| `Core\RevGMArg.cs` | 参数说明 | 面板据此显示帮助 + 执行前校验（`Int/IntRequired/Float/Bool/Str/Enum`） |
| `Core\RevGMFlags.cs` | 标记 | `HighRisk`（二次确认）/ `Hidden`（不进联想） |
| `Core\RevGMResult.cs` | 结果 | 成功与否 + 消息 + 耗时 |
| `Core\RevGMUsageException.cs` | 用法错误 | 业务抛它就等于"把这句话显示给测试同学" |
| `Implementation\RevGMRegistry.cs` · `RevGMCommand.cs` · `RevGMParser.cs` · `RevGMMatcher.cs` | 引擎内部 | 注册表 / 命令记录 / 分词 / 模糊匹配打分 |
| `Core\RevGMEntryAttribute.cs` | 可选 | 标记注册入口（让面板在不进 Play 时也能列出命令） |
| `Support\RevGMUnityHooks.cs` | 可选 | Unity 钩子：进 Play 时清一次命令表，避免"关闭 Domain Reload 时第二次 Play 撞重名而整批注册中断" |

编辑器侧：`Editor\RevGMCommand\RevGMWindow.cs`（面板）+ `RevGMEditorCatalog.cs`（命令目录：Play 读运行期、编辑期走 `[RevGMEntry]` 快照）。

| # | 参考实现的问题 | 出处 | 本框架的处理 |
|---|---|---|---|

## 五、三条铁律

1. **注册只写在一处**（组合根）—— 命令实现体里不要再注册别的命令，否则"有哪些命令"变得不可预测；
2. **参数不要自己解析字符串** —— 用 `args.Int(0, 默认值)`：解析失败会给你一句人话，而不是抛英文异常；
3. **业务拒绝要"有话说"** —— 抛 `RevGMUsageException("为什么不行")`，这句话会原样显示在面板上（别用静默 `return`）。

## 六、正式包策略（怎么保证不上线）

本框架**没有用编译宏裁剪**，而是用更硬的一条：

- 正式包里没人调 `RevGM.Register(...)` → 注册表是空的，程序集里只有几十行"空转"代码，**没有任何副作用**（没有静态构造、没有反射扫描、没有 Update）；
- 需要临时关闭：`RevGM.Enabled = false`（注册保留，执行一律拒绝）；
- 想把 GM 命令**整块删掉**：删掉注册入口 + 命令实现文件即可（框架代码可以留着，也可以一起删，没有耦合）。

## 七、常见错（对应参考实现 `07:225-233` 的错误表）

| 现象 | 原因 / 处理 |
|---|---|
| 面板里一条命令都没有 | 没注册；或编辑模式下没给注册方法加 `[RevGMEntry]`（Play 模式下不需要） |
| 点了执行没反应 / 报"需 Play 才能执行" | 编辑模式不执行命令（命令体常要碰运行时对象）；按 Play 再来 |
| `没有这条命令：xxx。你是不是想输入：…` | 名字打错了，按建议改；或直接用面板联想 |
| `「重置」匹配到 2 条命令` | 只写了末段名且有多条同名 → 写完整名（含分组） |
| `参数「数量」应该是整数，实际收到 "abc"` | 参数类型不对，框架在业务执行前就拦下了 |
| 命令返回失败但我没写检查 | 面板会用红色 HelpBox 显示失败原因；代码里判 `result.Success` |
| 高危命令点了不执行 | 弹了二次确认框被取消了；确认或 `Ctrl+Enter` 跳过 |

## 八、已知边界（诚实清单）

1. **联想是"字符级"匹配**：中文命令请打中文子串（`加金` → `经济/加金币`）；**拼音首字母缩写（如 `jjb`）不支持**（需要一张拼音表，不在轻量范围内）。英文名命令（`Battle/AddGoldInstant`）支持缩写 `agi`。
2. **编辑模式不执行命令**：避免"命令体碰了运行时对象、在编辑器里直接崩"。
3. **不做客户端权限伪造**：高危标记只是"提醒 + 二次确认"，真正的权限必须由服务端裁决（这一点与参考实现的结论一致：`05:166-180`）。
4. **`GetRequired` 式的强制校验没有**：本框架的 `Suggest` 只给建议，不做拦截 —— 名字错了就是"没找到"。
5. **命令名里不能有空格**（空格是命令与参数的分隔符），分组用 `/`。
